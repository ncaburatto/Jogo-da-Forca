# Requisitos Funcionais

## Requisitos Funcionais (O sistema faz)

1. Validação de letras, se a mesma já foi utilizada ou se é válida
2. Atualizar o desenho do boneco a cada letra incorreta
3. Permitir inserir apenas uma letra por vez
4. Aceitar somente letras, ignorando números e caracteres especiais e espaços
5. O jogo deve encerrar ap+os um número máximo de erros, geralmente 6
6. Mostrar o número de letras da palavra secreta por underlaines ou traços

## Requisitos Não Funcionais (Como o sistema deve ser)

1. A interação com o usuário deve ser clara e mostrar o estado atual da forca, çetras incorretas e a palavra parcialmente revelada
2. O tempo de resposta deve ser imediato
3. O código deve ser organizado para facilitar a adição de novas palavras à lista de sorteio
